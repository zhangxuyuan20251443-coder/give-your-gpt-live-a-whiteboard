# 动态白板

白板是你回答时的第二块屏幕。聊天正文照常写完整；白板上放的是你亲手画的画面：此刻最该被看见的一句话，和让它一眼就懂的图形与动作。

它比生成网页好在四点：
- **立刻出现：**白板直接全屏弹出，没有文件，也不用切到浏览器。
- **随讲随改：**你继续画、改，画面原位变形；翻页时同名的东西会平滑地变过去。
- **能互动：**用户按空格往下看，打字或点选就能回答你。
- **跟着节奏：**元素按你讲的顺序和时间出场。

```sh
W="<本技能目录>/scripts/board.py"      # 例如 ~/.codex/skills/dynamic-whiteboard/scripts/board.py
python3 -B "$W" say <<'S'
== 潮汐，是月球在**拉**海水。
潮汐从哪来？ | 8,18 l light
月球在**拉**海水 | 8,30 xl
o 30,66 10 +#7FB2E5 @earth
o 82,30 4 +ink orbit @moon
~> 77,33 60,42 42,58 orange w3 flow @pull
S
```

每次调用输出一行 JSON：`ok` 表示是否成功，`status` 说明发生了什么，`hint` 告诉你下一步，`warnings` 是渲染引擎实测出的排版问题。会话、版本、回答编号都由脚本自动维护，你不用管。

## 什么时候用

**适合：**
- 机制、因果、流程、循环、变化、对比、空间关系
- 能拆成几步的讲解
- 要用户跟着做的步骤，比如训练动作、操作步骤，一步一页

**不适合：**
- 一句话就能答完的事实
- 代码、大表格、只用来查阅的长清单
- 用户刚按 Esc 收起了白板（脚本会返回 `dismissed`）

## 速写

舞台是 16:10 的画面。坐标都写 0–100：x 是宽度的百分比，y 是高度的百分比，原点在左上角。每页以 `==` 开始，接下来每行画一个元素；行尾可以加 `// 注释`。

```
== 这一页要说的话 | push            // 换页方式：blend（默认）push lift zoom cut；bg:颜色 换底色
文字 | 参数                          // 文字。没写坐标就接在上一段下面
o x,y 半径                           // 圆，半径按高度 %
b x,y 宽x高                          // 方框，x,y 是左上角；round 圆角
- 点 点 …                            // 线 / 折线
-> 点 点 …                           // 箭头（<- 起点带头，<-> 两头都带）
~ 点 点 …                            // 平滑曲线穿过各点，首尾同点时闭合；~> <~ <~> 带箭头
~> a b 0.3                           // 两点加一个数：弧线，数字是弯曲度，正负决定弯向哪边
w x,y 宽x高 周期 [振幅]              // 波
p 点 点 点 …                         // 多边形（默认填杏色）
blob x,y 大小 [种子]                 // 有机色块（默认填杏色）
arc x,y 半径 起角 止角               // 弧：0° 在正上方、顺时针；加 +颜色 变扇形
i 名字 x,y 大小                      // 图标（Lucide 英文名：heart dumbbell brain chart-line …），x,y 是中心
img 路径 x,y 宽x高                   // 本机图片
cam x,y 倍数                         // 镜头推近到这一点；cam reset 拉回全景
```

**文字内容的写法：**
- `**重点**`：加粗并上强调色
- `__高亮__`：荧光笔从左往右划过
- `~~删除~~`：删除线
- `{pink:文字}`：给一段换颜色
- `\n`：换行

**参数**写在坐标后面，顺序随意：

| 类 | 写法 |
|---|---|
| 字号 | `xs s m l xl xxl huge`（2.4 / 3.2 / 4.5 / 7 / 10 / 15 / 22），或数字，单位是画面高度的 % |
| 字体 | `sans`（苹方，默认）、`serif`（宋体）、`kai`（楷体）、`hand`（手写）、`round`（圆体）、`mono`（等宽） |
| 字重 | `thin light regular medium bold heavy` |
| 排版 | `c` 居中，`r` 右对齐；`w:40` 宽度 40% 自动换行；`lh:1.4` 行距；`nowrap` 不换行 |
| 颜色 | `ink orange pink peach muted line white`，或 `#RRGGBB`。`+颜色` 是填充，`+orange>pink` 是渐变 |
| 线 | `w3` 线宽，`dash` 虚线，`dots` 点线，`dot` 圆点跑一遍，`flow` 圆点一直沿线流动 |
| 质感 | `40%` 透明度，`-6deg` 旋转，`glow` 发光，`shadow` 阴影，`round` 圆角，`top` 压在文字上面 |
| 出场 | `rise fade pop slide draw wipe blur zoom spin drop bounce grow stretch left right up down type chars none` |
| 持续 | `float pulse breathe sway bob orbit turn spinfast blink shake` |
| 移动 | `to:x,y` 出场后移到某处；`along:@名字` 沿那条线走（加 `loop` 一直走） |
| 节奏 | 默认逐行出场，间隔 0.15 秒；`&` 和上一行同时；`+2.5` 在第 2.5 秒出场；`dur:1.2` 调时长；`slow` `fast` |
| 位置 | `below:@名字` `above:@名字` `left:@名字` `right:@名字` `on:@名字`，按真实大小贴在旁边（`gap:3` 调间距） |
| 其他 | `@名字` 命名；`count` 数字从 0 数到目标值 |

**默认值：**
- 文字：`m` 号，墨色，`rise` 出场。
- 线、箭头、曲线、波：橙色，逐笔画出，箭头在画完时出现。
- 圆和方框：有填充时 `pop` 弹出，没填充时描边。
- 图标：逐笔画出。
- 整页一行文字都没写时，`==` 那句话会自动显示，`**重点**` 部分加粗上色。

## 画得好

1. **先想画面，再写行。**这句话里的「动作」是什么，就画什么：
   - 推和拉：箭头加 `left`、`right`、`to:`
   - 增长：`grow`、`up`、`count`
   - 传播和流动：波、`flow`
   - 循环：闭合曲线加 `flow`，或 `orbit`
   - 对比：大小和颜色的反差
   - 强调：`__高亮__`，或用一条闭合曲线把它圈起来
   - 细节：`cam` 推近
2. **一个焦点。**每页只让一样东西最大、最亮。字号控制在三档以内：小标签 `s muted`，主句 `l` 或 `xl`，数字可以 `huge`。
3. **克制用色。**墨色为主，橙色只给最重要的那一处；粉色和杏色当底色、做氛围。渐变色块配 20–40% 透明度，衬在主体后面。
4. **留白。**文字和图形分区摆放，别挤在一起。底部 12% 留给输入框和选项，左右各留 6% 以上。
5. **节奏跟着话走。**先出现的先被看见。用 `+秒数` 把元素排到你讲到它的那一刻；一页里持续动作只用一两个，多了会乱。
6. **跨页连贯。**同一个东西在两页里用同一个 `@名字`，翻页时它就地变形，比如人从「下蹲」变成「站起」、圆移到另一边、波变大。
7. **按反馈修。**你看不见屏幕。`say` 和 `edit` 会附上渲染引擎实测的 `warnings`：重叠、线穿过文字、超出画面、字太小。照着挪位置或改字号再 `edit`。
8. **看例子。**`examples/潮汐.sketch` 和 `examples/哑铃训练.sketch` 是完整的示范：构图、节奏、跨页变形都有。

## 边讲边画

讲到下一步时，直接改当前页：

```sh
python3 -B "$W" edit <<'S'
@pull pink w4                 // 改：@名字 后面写新参数（新的覆盖旧的）
x @moon                       // 删
-> 78,52 58,52 orange dot     // 加：写一行新的，从现在开始出场
cam 40,52 1.4                 // 镜头推近
== 近的一侧被拉得更高。         // 换主句
S
```

## 命令

| 命令 | 作用 |
|---|---|
| `say <<'S' … S` | 送 1–8 页。白板没开就打开；用户看完前面的页才跳到新页，否则排在后面按空格看 |
| `say "一句话"` | 只有一句话的页 |
| `say --now` / `--queue` / `--new --topic 标题` | 立刻跳页 / 只排队 / 新开一块白板，替换正在显示的内容 |
| `ask "问题？" --choice 甲 --choice 乙 [--wait 45]` | 提问并等用户点选、按数字键或打字，最多等 120 秒 |
| `wait [--wait 45]` | 继续等用户输入 |
| `edit <<'S' … S` | 改当前页，写法见上 |
| `close` | 讲完收起 |
| `check <<'S' … S` | 只校验，不显示；排版提示是估算 |
| `status` `describe` `doctor` `build` `demo [哑铃训练]` | 状态 / 语法速查 / 检查环境 / 编译原生窗口 / 看示例 |

同一个话题继续 `say`。话题结束、用户转去做别的事时再 `close`，不要发完就收。

## 用户的回应

白板上的输入，只有在你调用 `ask` 或 `wait` 时才会交给你。要是你调用 `say`、`edit`、`close` 时用户已经写了东西，脚本会返回 `interrupted`，并带上他的原话。

| status | 你该做 |
|---|---|
| `shown` / `queued` / `edited` | 继续讲；有 `warnings` 就修 |
| `answer` | 原话在 `answer` 里。据此决定下一句，用 `say` 回应（脚本会自动接在这条回答后面） |
| `continue` | 用户在最后一页按了空格，意思是「继续」，讲下一点 |
| `interrupted` | 用户插话了，你这次的操作没有执行；先回应他 |
| `timeout` | 还没回应；可以再 `wait`，否则用文字继续 |
| `closed` / `dismissed` | 用户按 Esc 收起了白板；用文字继续，用户再次想看时才用 `say --new` |
| `editing` | 用户正在打字，`wait` 等他发出来 |
| `busy` | 白板正在显示别的内容，确认要替换再加 `--new` |
| `invalid` | 按 `error` 里指出的行号和 `hint` 改 |

如果宿主限制单条命令的时长，就用短一点的 `--wait`（比如 20 秒）多等几轮。

## 出问题时

- 白板没出现、返回 `opening` 或 `launch-failed`：运行 `doctor`，按每项的 `fix` 修复，再运行 `demo` 确认。
- 还没编译原生窗口时，白板会用 Chrome 类浏览器的无边框窗口显示；用户在 Mac 上运行一次 `build` 后，就会换成原生全屏窗口。
- 白板用不了时，告诉用户情况，然后用文字继续。不要改技能源码，也不要另写脚本去驱动播放器。
- 完整语法和更多手法见 `references/sketch.md`；需要逐个数值精确控制时，场景 JSON 格式见 `references/scene.md`。
- 只支持 MCP 的宿主可以运行 `board.py mcp`：`whiteboard_say`、`whiteboard_edit`、`whiteboard_check` 接收 `sketch` 字符串，另有 `whiteboard_ask`、`whiteboard_wait`、`whiteboard_close`、`whiteboard_status`、`whiteboard_describe`。
