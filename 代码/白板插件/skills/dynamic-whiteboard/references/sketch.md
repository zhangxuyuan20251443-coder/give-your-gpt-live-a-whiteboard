# 速写：完整说明

SKILL.md 里的速查表已经覆盖全部语法。这份文档补充细节：每种元素的确切含义、动画怎么排、跨页变形和编辑的规则，以及一些常用手法。

## 舞台和单位

- 舞台是 16:10，内部按 1600×1000 绘制，会等比缩放到屏幕上，多出的边用同样的纸色填满。
- x、y 都是 0–100 的百分比：x 是宽度的百分比，y 是高度的百分比。所以 `50,50` 永远在正中。
- 字号、圆的半径、图标大小都按画面高度的 %。字号 10 表示字高约为画面高度的十分之一。
- 线宽 `w1` 约 1.8 个舞台像素，线条默认 `w2`。

## 页

```
== 这一页要说的话 | 页参数
```

- 一次 `say` 最多 8 页。`==` 后面的句子是这一页的话（可以带 `**重点**`），也是页标题。
- 整页没有文字元素时，这句话会自动显示在左侧：有 `**重点**` 时分成两行；超过 14 字时在最后一个逗号处断开。
- 页参数：
  - 换页方式：`blend`（默认，淡入淡出）、`push`（旧画面向左推走）、`lift`（向上抬走）、`zoom`（放大淡出）、`cut`（直接切换）。
  - `bg:颜色`：换这一页的底色。
  - `plain`：用播放器的极简对话页。
  - 文字参数（坐标、字号、颜色、字体……）：作用于自动显示的那句话。

## 元素细节

| 写法 | 说明 |
|---|---|
| `文字 \| 参数` | 坐标是锚点：默认左上角；加 `c` 时是顶部中点，加 `r` 时是右上角。不写宽度时，一行写到画面边缘才换行；写了 `w:40` 就在 40% 宽处换行。单段最多 200 字 |
| `o x,y r` | 圆心和半径。只写 `+颜色` 是实心圆；只写颜色是空心圆；两者都写就是带边的实心圆 |
| `b x,y 宽x高` | 方框。`round` 圆角 1.6，`round:4` 自定义圆角 |
| `- / ->` | 2–24 个点。`->` 末端有箭头，`<-` 起点有箭头，`<->` 两头都有 |
| `~ / ~>` | 平滑曲线会穿过每一个点（最多 24 个）。首尾写同一个点就闭合，可以用来手绘一个圈；闭合后加 `+颜色` 会被填满 |
| `~> a b 0.3` | 只有两个点再跟一个数时画成弧线。数字是弯曲度，0.2–0.5 比较自然 |
| `w x,y 宽x高 周期 振幅` | 正弦波，周期 0.5–5，振幅 0–1（相对框高的一半） |
| `p 点 点 点` | 直边多边形，默认填杏色 |
| `blob x,y 大小 种子` | 圆润的不规则色块，适合做背景、海水、细胞、区域。换一个种子数就换一个形状 |
| `arc x,y 半径 起角 止角` | 0° 在正上方、顺时针。`arc 50,50 20 0 270` 是四分之三圈；加 `+颜色` 变成扇形，可以拼饼图；配合 `slow` 适合当进度环 |
| `i 名字 x,y 大小` | Lucide 图标（1500 多个），x,y 是中心。颜色是描边色；`+颜色` 填充；`w2` 调线宽。名字写错时，脚本会给出相近的名字 |
| `img 路径 x,y 宽x高` | 本机图片（png、jpg、gif、webp、svg），默认裁切填满。`round:3` 圆角 |
| `cam x,y 倍数` | 镜头在指定时刻推近到这一点（倍数 1–6），`dur:` 调推镜时长；`cam reset` 拉回全景。翻到下一页会自动复位 |

## 动画

**出场**：元素按行的顺序出场，默认每行间隔 0.15 秒。

| 写法 | 作用 |
|---|---|
| `&` | 和上一行同时出场 |
| `+秒数` | 在这一页的第几秒出场，最长 59 秒，后面的行从这里接着排 |
| `dur:秒数` | 改出场时长；线条默认按长度决定，越长画得越久 |
| `ease:back` | 带回弹；还可选 `smooth`、`linear`、`out`（默认） |

可选的出场效果：

| 写法 | 效果 |
|---|---|
| `rise` | 上浮淡入（文字默认） |
| `fade` | 淡入 |
| `pop` | 弹出（圆默认） |
| `slide` | 从左侧轻滑入 |
| `draw` | 逐笔画出（线、图标、空心框默认）；闭合并填色的路径会先画描边，再填色 |
| `wipe` | 从左到右擦出 |
| `blur` | 从模糊到清晰 |
| `zoom` | 从大缩到正常（图片默认） |
| `spin` | 转着出现 |
| `drop` | 从上方掉下 |
| `bounce` | 落下后弹跳 |
| `grow` | 从底部长高，适合柱子 |
| `stretch` | 从左侧拉长，适合进度条 |
| `left` `right` `up` `down` | 从左、右、下、上较远处滑入 |
| `type` | 打字机效果，逐字出现 |
| `chars` | 每个字依次弹出 |
| `none` | 直接出现 |

**持续**：出场后一直循环，可以叠两种。

| 写法 | 效果 |
|---|---|
| `float` | 上下浮 |
| `pulse` | 缩放跳动 |
| `breathe` | 明暗呼吸 |
| `sway` | 左右摆 |
| `bob` | 浮着轻摆 |
| `orbit` | 小圈绕行 |
| `turn` | 慢转 |
| `spinfast` | 快转 |
| `blink` | 闪烁 |
| `shake` | 抖三下 |

**沿线运动：**
- 线条上：`dot` 让一个圆点跑一遍；`flow` 让三个圆点一直沿线流动，适合表现信号、电流、物质流。`dot:pink` 改圆点颜色。
- 其他元素：`along:@线的名字` 让它沿那条线走一遍，加 `loop` 一直走。

**其他：**
- `to:x,y`：出场后用约 1.2 秒移到新位置。圆以圆心为准，文字以锚点为准，方框和图片以左上角为准，线以第一个点为准。
- `count`：文字里的第一个数字从 0 数到目标值，小数位保留。
- 文字里的 `__高亮__` 会在文字出场后被荧光笔划亮。

## 相对位置

`below:@名字` `above:@名字` `left:@名字` `right:@名字` `on:@名字` 会在渲染时按被引用元素的真实大小来摆放，所以标签总能贴准，不用估算宽度：

```sketch
== 相对位置
o 40,45 12 +peach @cell
细胞核 | below:@cell m muted
7.5 | 60,30 huge heavy orange @kg
kg | right:@kg l light
```

`gap:数字` 调间距，单位是百分比。只能引用同一页里有名字的元素。

## 跨页变形

- 相邻两页里同名的元素（`@名字` 相同、类型相同）会从旧样子平滑变到新样子：位置、大小、颜色、路径形状都会过渡。路径的点数和结构一致时，形状逐点变形；不一致时交叉淡化。
- 没命名的文字按内容自动命名，内容完全相同才变形（比如重复的小标签），不同内容在原位淡出淡入。
- 没命名的形状按类型和顺序自动命名（`o1`、`b1`、`l1`、`a1`、`c1`、`w1`、`p1`、`blob1`、`arc1`、`i1`、`img1`），所以相邻两页同序号的同类形状也会变形。不想要时，给它们起不同的名字。

## edit

```
@名字 参数        // 新参数覆盖同类的旧参数，比如 @pull pink w4、@ball to:80,40、@label 30,60
@名字 新内容      // 改文字；要连参数一起改，写成 @名字 新内容 | 参数
x @名字           // 删
任意元素行        // 加：从现在开始出场，依次出现
cam x,y 倍数      // 推镜头
== 新的一句话     // 换主句；自动显示的句子会跟着换
```

- 只有用速写画的页才能用速写 edit。
- `edit` 返回这一页所有元素的名字（`ids`），自动命名的也在其中。
- 用户刚作答时，改好的画面会作为新的一页接在回答后面。

## 排版反馈

- `say` 和 `edit` 成功后，渲染引擎会实测这一页，把问题放进 `warnings`：文字重叠、线穿过文字、超出画面、字太小（小于约 1.5% 高）。每条都写明是第几行、哪段字。
- `check` 不打开窗口，所以给的是估算结果，仅供参考。

## 上限

| 项 | 上限 |
|---|---|
| 每页元素 | 48 个 |
| 每页文字 | 合计 600 字，单段 200 字 |
| 一次 `say` | 8 页 |
| 白板保留 | 最近 80 页 |

其实远用不到这么多：好画面通常是 4–10 个元素。

## 手法

画一个手绘圈，圈住重点：

```sketch
== 不用练到力竭。
动作一变形就停 | 50,28 l light c
不用练到力竭 | 50,42 xl c
~ 30,43 50,38.5 70,43 72,55 50,61 28,55 30,43 orange w2 slow +0.8
```

进度环加倒数：

```sketch
== 组间休息 60 秒。
arc 50,46 26 0 360 line w2
arc 50,46 26 0 300 orange w5 slow
60 | 50,34 huge heavy c count
秒 | 50,60 m muted c +0.6
```

流程加流动：

```sketch
== 请求从浏览器一路走到数据库。
i monitor 14,50 10 @a
i server 50,50 10 @b
i database 86,50 10 @c
~> 20,50 44,50 0.25 orange w3 flow
~> 56,50 80,50 0.25 orange w3 flow +0.4
浏览器 | below:@a s muted
服务器 | below:@b s muted
数据库 | below:@c s muted
```

柱子长高，最后数字跳出来：

```sketch
== 三个月，销量翻了两番。
b 20,70 10x20 round +peach grow
b 40,50 10x40 round +pink grow +0.3
b 60,20 10x70 round +orange grow +0.6
×4 | 76,14 xl heavy orange zoom +1.2
- 14,90 76,90 line w1
```

镜头推近看细节：

```sketch
== 近的一侧被拉得更高。
o 34,52 15 +#7FB2E5 @earth
blob 37,52 21 +peach>pink 40% breathe @sea
-> 78,52 58,52 orange w4 dot
近侧 · 涨潮 | 48,30 m bold orange
cam 40,52 1.3 +1.5
```

更完整的例子见 `examples/潮汐.sketch`、`examples/哑铃训练.sketch`。
